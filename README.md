# ForgeWorldGen

[![Paper 26.3](https://img.shields.io/badge/Paper-26.3-blue)](https://papermc.io/)
[![Java 25](https://img.shields.io/badge/Java-25-orange)](https://adoptium.net/)

**Blazing-fast custom terrain generation for Paper.** Rounded-craggy mountain ranges with escarpment cliffs, deep river valleys and alpine lakes, rare basalt volcanoes with crater bowls, 18 original climate-blended biomes across Earth's greatest hits — and deterministic custom flora, from jungle giants to glacial boulders — generated by a hand-rolled, allocation-free simplex noise engine that does the whole chunk in a single pass.

</div>

## Why it's fast

Most custom generators make several passes over every chunk and allocate per block. ForgeWorldGen does it differently:

- **Original simplex noise in pure Java** — zero allocation in hot loops, thread-safe, ~1µs per terrain column
- **One pass per chunk** — stone, dirt, surface mosaic, water, volcano craters and trees all happen inside a single `generateNoise` sweep; the separate surface step is disabled so work is never repeated
- **Bulk fills** — `setRegion` for stone/dirt/water columns instead of per-block calls
- **Deterministic hash-based flora** — trees are placed from a seeded hash, stable across restarts, no extra passes
- **Live speed readout** — `/fgen pregen` reports real chunks/sec while it works

## The eighteen biomes

Climate (temperature, moisture, altitude) is sampled from continuous noise fields, plus large-scale region territories, so biome borders follow smooth contour lines — no hard edges.

| Biome | Vanilla base | Character |
|---|---|---|
| Ember Highlands | Windswept Hills | Steep rocky mountain slopes |
| Frostcap Peaks | Frozen Peaks | Snow-capped summits |
| Verdant Vale | Meadow | Rolling green valleys |
| Mistwood | Dark Forest | Dense dark canopy forest, rare jungle giants |
| Whispering Pines | Old Growth Pine Taiga | Cold coniferous hills |
| Golden Savanna | Savanna | Dry golden grassland, flat-top trees |
| Sunbaked Dunes | Desert | Hot dunes with cacti |
| Blooming Meadow | Flower Forest | Flower-filled meadows |
| Tidewater Shallows | Beach | Shallow seas, beaches, palms at the waterline |
| Ashen Caldera | Stony Peaks | Basalt volcano slopes, lava crater bowl |
| Rolling Plains | Plains | Classic rolling grassland, the mellow default |
| High Plains | Savanna Plateau | Elevated grassland plateau with bluff edges |
| Deep Ocean | Deep Ocean | Deep open water with occasional islands |
| Barren Wasteland | Badlands | Red-gray mottled badlands, dead snags, lava pools |
| Geyser Basin | Meadow | Hot-spring pools, geyser cones, mineral mats (Yellowstone) |
| Granite Valley | Windswept Hills | Pale granite walls, a great dome, waterfalls (Yosemite) |
| Painted Canyon | Badlands | Banded red/cream/ochre strata mesas (Grand Canyon) |
| Dune Sea | Desert | Rolling sand dunes with slip faces (Sahara) |

Surfacing is slope-driven, not a grass carpet: steep faces expose banded rock, gentle slopes grow grass or hold snow, and the snow line follows slope *and* altitude. A dedicated decoration pass adds mottled speckle, pale erosion streaks, scree at cliff bases, dirt patches, wildflowers, bushes, glacial-erratic boulders and nine original tree designs — all cheap deterministic functions, so generation stays fast.

## Commands

| Command | Permission | Description |
|---|---|---|
| `/fgen create <name> [seed]` | `fgen.admin` | Create a new ForgeWorldGen world |
| `/fgen tp <world>` | `fgen.tp` | Teleport to a world |
| `/fgen pregen <world> <radius>` | `fgen.admin` | Pre-generate chunks (radius in chunks, max 48) with live chunks/sec readout |
| `/fgen cancel` | `fgen.admin` | Stop a running pre-generation |
| `/fgen reload` | `fgen.admin` | Reload config.yml |

## Permissions

| Permission | Default | Description |
|---|---|---|
| `fgen.admin` | op | Create worlds, pre-generate, cancel, reload |
| `fgen.tp` | op | Teleport to ForgeWorldGen worlds |

## Configuration

```yaml
generation:
  sea-level: 62          # ocean level
  volcano-rarity: 0.1    # chance per 512x512 cell (~1 volcano per 10k chunks); 0.0 disables
  tree-density: 1.0      # multiplier on flora density; 0.0 disables trees
  mountain-scale: 1.0    # multiplier on mountain height
  mountain-rarity: 0.5   # 0.0-1.0: how much land becomes dramatic ranges (Earth-like default)
features:
  caves: true            # vanilla cave carvers on ForgeWorldGen terrain
  decorations: true      # vanilla decorations (ores, flowers) on our terrain
  structures: true       # vanilla structures (villages, etc.) on our terrain
  mobs: true             # mob spawning
world:
  auto-manage: true      # re-attach our generator to managed worlds on restart
managed-worlds: []       # maintained by the plugin; /fgen create adds entries
messages:
  prefix: "<gold>[ForgeWorldGen]</gold> "
```

> **Note:** worlds created with `/fgen create` are recorded under `managed-worlds`. On server restart Bukkit auto-loads world folders but forgets custom generators — with `auto-manage` on, ForgeWorldGen unloads and reloads those worlds with its generator attached, so you never get vanilla chunks at the borders.

> **Known limitation (Paper 26.3 alpha):** worlds created at runtime via `/fgen create` currently live in memory — Paper 26.3's alpha build does not write their folders to disk on `save()`/`save-all` (the Doortals pocket world behaves the same way on this build). They work fully while the server runs; expect them to need re-creation after a restart until Paper's world persistence catches up.

## Building

Requirements: JDK 25, Gradle 9.7.1.

```bash
gradle build          # canonical build (bigpc / CI)
# or, where the Gradle daemon can't run:
bash build.sh         # direct javac against Paper 26.3, -Werror clean
```

The jar lands at `ForgeWorldGen-1.2.0.jar`. Drop it in `plugins/` and restart.

## API notes (Paper 26.3)

Researched against `paper-api:26.3.build.35-alpha`, not assumed:

- `generateNoise(WorldInfo, Random, int, int, ChunkData)` — single terrain pass
- `getDefaultBiomeProvider(WorldInfo)` — our climate biome provider
- `shouldGenerateSurface()` returns `false` — surfacing happens inside the noise pass
- `shouldGenerateCaves/Decorations/Structures/Mobs()` — vanilla pipeline on our terrain, config-toggled
- `ChunkGenerator.isParallelCapable()` and `shouldGenerateBedrock()` are **deprecated in 26.3 with no replacement** — not overridden; bedrock is placed in the noise pass and the generator is thread-safe by construction
- Per-chunk `shouldGenerate*(WorldInfo, Random, int, int)` variants delegate to the no-arg versions, so overriding the no-arg flags is correct
